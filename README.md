# Where Americans Moved — and the Money That Moved With Them — MoveNoble dataset

This repository contains the dataset behind the MoveNoble study "Where Americans Moved — and the Money That Moved With Them".

## Data files

- `state-profiles.csv` — state-level migration profiles for 50 states + DC: inflow, outflow and net households, net AGI, average AGI in/out, and top origins/destinations.
- `top100-routes.csv` — the top 100 state-to-state migration routes, with households, people and AGI.

## Key figures

- Texas was the top net gainer (+56,473 households); California was the top loser (−100,397 households); Florida had a net AGI inflow of +$20.65B; the largest single route was California to Texas, 44,417 households.

## Source

- IRS SOI 2022–2023 migration data and Census NST-EST2024 population estimates.
